Kebijakan Privasi

Terakhir diperbarui: 4 November 2026

Dokumen ini menjelaskan bagaimana aplikasi Jeda Dulu Bot ("aplikasi") menangani data. Aplikasi dijalankan oleh pemilik channel Jeda Dulu hanya untuk mengelola akun miliknya sendiri.

1. Data yang diakses

  • Token otorisasi (OAuth) untuk akun YouTube/Google, Instagram/Facebook, dan TikTok milik pemilik channel.
  • Data channel milik pemilik sendiri: daftar video, judul, deskripsi, dan statistik (tayangan, durasi tonton, retensi, suka, komentar, pengikut).
  • Komentar publik pada video milik pemilik, untuk dirangkum dan dianalisa.

Aplikasi tidak mengumpulkan data pribadi pengunjung atau penonton secara individual, dan tidak memakai cookie pelacak.

2. Cara data dipakai

  • Mengunggah video milik pemilik ke akun milik pemilik.
  • Membuat ringkasan performa (analitik) untuk membantu pemilik memilih topik dan jadwal video berikutnya.

3. Penyimpanan dan keamanan

Token disimpan terenkripsi akses (izin berkas terbatas) di server pribadi pemilik dan tidak dimasukkan ke repositori kode. Statistik disimpan di basis data lokal di server yang sama. Data tidak dijual, tidak dibagikan, dan tidak dipindahkan ke pihak ketiga, kecuali ke layanan platform yang bersangkutan (YouTube, Meta, TikTok) sebagai bagian dari fungsi unggah dan baca statistik, serta penyedia model AI untuk meringkas statistik tanpa data identitas.

4. YouTube API Services

Aplikasi menggunakan YouTube API Services. Dengan memakai aplikasi ini, Anda terikat pada Ketentuan Layanan YouTube. Penanganan data oleh Google diatur oleh Kebijakan Privasi Google. Anda dapat mencabut akses aplikasi kapan saja melalui pengaturan keamanan Google.

5. Penyimpanan dan penghapusan

Data statistik disimpan selama channel aktif. Token dihapus bila akses dicabut atau aplikasi dihentikan. Permintaan penghapusan data dapat dikirim ke email di bawah dan akan diproses dalam 30 hari.

6. Anak-anak

Aplikasi tidak ditujukan untuk anak di bawah 13 tahun dan tidak mengumpulkan data dari mereka.

7. Perubahan

Kebijakan ini dapat diperbarui. Tanggal pembaruan terbaru tertera di bagian atas.

Privacy Policy

Last updated: 4 November 2026

This document explains how the application Jeda Dulu Bot (the "App") handles data. The App is operated by the owner of the Jeda Dulu channel solely to manage the owner's own accounts.

1. Data accessed

  • OAuth authorization tokens for the owner's own YouTube/Google, Instagram/Facebook and TikTok accounts.
  • The owner's own channel data: video list, titles, descriptions and statistics (views, watch time, retention, likes, comments, followers).
  • Public comments on the owner's own videos, to be summarised and analysed.

The App does not collect personal data about individual visitors or viewers and does not use tracking cookies.

2. How data is used

  • Uploading the owner's own videos to the owner's own accounts.
  • Producing performance summaries (analytics) to help the owner choose future topics and schedules.

3. Storage and security

Tokens are stored with restricted file permissions on the owner's private server and are never committed to a code repository. Statistics are kept in a local database on the same server. Data is not sold, shared or transferred to third parties, except to the relevant platform services (YouTube, Meta, TikTok) as part of the upload and statistics-reading functions, and to an AI model provider to summarise statistics without identifying information.

4. YouTube API Services

The App uses YouTube API Services. By using the App you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. You can revoke the App's access at any time via the Google security settings page.

5. Retention and deletion

Statistics are kept while the channel is active. Tokens are deleted when access is revoked or the App is discontinued. Data deletion requests can be sent to the email below and will be handled within 30 days.

6. Children

The App is not directed at children under 13 and does not collect data from them.

7. Changes

This policy may be updated. The latest update date appears at the top.
